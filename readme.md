# RPG Sheet Console v3.0 - TTRPG Engine

A lightweight, web-based character management system and mechanical calculator for tabletop role-playing games. It seamlessly handles complex combat math, multi-weapon arsenals, damage calculations, and resource tracking.

## Features

* **Advanced Theme Engine:** Switch between 8 unique visual styles—including Apple Style, Proxy Terminal, Cyber Futuristic, and Playful Earth—with smooth transitions.
* **Weapons Arsenal:** Manage multiple equipped weapons complete with 1:1 image uploaders, lore descriptions, and custom enchantment modifiers.
* **Interactive Whiteboard Notes:** Create, drag, resize, and type freely on a sticky-note canvas to keep track of campaign details.
* **Damage Applier & Dice Roller:** Calculate percentage or flat damage outputs against vitals and roll d20s with full critical success and failure screen animations.
* **Local Folder Integration:** Scan and launch companion HTML tools directly from a local directory via the External Webs tab.
* **Zero Installation:** Built entirely with plain HTML, CSS, and Vanilla JavaScript with robust local storage and multi-format JSON backup support.

## How to Run

1. Save `index.html`, `style.css`, and `script.js` into the same folder on your computer.
2. Double-click `index.html` to open the application in any modern web browser.
3. Use the global menu drawer to manage profiles, switch themes, and organize your campaign.
