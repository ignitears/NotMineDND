# RPG Sheet Console v3.1 - TTRPG Engine

A lightweight, web-based character management system and mechanical calculator for tabletop role-playing games. It seamlessly handles complex combat math, multi-weapon arsenals, damage calculations, and resource tracking.

## Features

* **Advanced Theme Engine:** Switch between 8 unique visual styles—including Apple Style, Proxy Terminal, Cyber Futuristic, and Playful Earth—with smooth transitions[cite: 13].
* **Weapons Arsenal:** Manage multiple equipped weapons complete with 1:1 image uploaders, lore descriptions, and custom enchantment modifiers[cite: 13].
* **Inventory & Coin Pouch:** Manage platinum, gold, silver, and copper coins with quick increment/decrement controls, plus a dynamic backpack featuring item stacking, live search filtering, and custom tagging.
* **Interactive Whiteboard Notes:** Create, drag, resize, and type freely on a sticky-note canvas to keep track of campaign details[cite: 13].
* **Damage Applier & Dice Roller:** Calculate percentage or flat damage outputs against vitals with dynamic health bars and roll d20s with full critical success and failure screen animations[cite: 13].
* **Local Folder Integration:** Scan and launch companion HTML tools directly from a local directory via the External Webs tab[cite: 13].
* **Zero Installation:** Built entirely with plain HTML, CSS, and Vanilla JavaScript with robust local storage and multi-format JSON backup support[cite: 13].

## How to Run

1. Save `index.html`, `style.css`, and `script.js` into the same folder on your computer[cite: 13].
2. Double-click `index.html` to open the application in any modern web browser[cite: 13].
3. Use the global menu drawer to manage profiles, switch themes, and organize your campaign[cite: 13].
